## 6. NFT 서버 (Arweave 업로드)

### 6.1 프로젝트 구조

```
nft/
├── src/
│   └── server.js      # Express 서버 (Irys/Arweave)
├── package.json
└── package-lock.json
```

### 6.2 환경 변수 설정

NFT 서버는 Arweave(Irys) 업로드를 담당합니다.

**.env 파일 작성** (nft/.env):

```bash
# 서버 설정
HOST=0.0.0.0
PORT=3200
NODE_ENV=development

# Arweave/Irys 설정
IRYS_NETWORK=mainnet
IRYS_TOKEN=ethereum
PRIVATE_KEY=your_wallet_private_key

# 업로드 설정
MAX_FILE_SIZE=10485760  # 10MB
ALLOWED_EXTENSIONS=jpg,jpeg,png,pdf
```

**주의사항**:
- `PRIVATE_KEY`는 실제 지갑의 Private Key 필요
- Arweave 업로드 비용이 발생하므로 충분한 잔액 필요
- `.env` 파일은 절대 Git에 커밋하지 말 것

### 6.3 빌드 및 실행

NFT 서버는 JavaScript로 작성되어 별도 빌드 과정이 필요 없습니다.

```bash
cd nft

# 의존성 설치
npm ci

# 서버 실행
node src/server.js

# 또는 package.json 스크립트 사용 (있는 경우)
npm start
```

### 6.4 주요 기능

- **파일 업로드**: Multer를 통한 멀티파트 파일 업로드
- **Arweave 저장**: Irys를 통한 영구 분산 저장
- **메타데이터 관리**: NFT 메타데이터 생성 및 업로드

### 6.5 API 엔드포인트


## 8. Blue-Green 무중단 배포

### 8.1 배포 전략 개요

본 프로젝트는 Blue-Green 배포 방식을 사용합니다:
- **Blue**: 현재 운영 중인 서비스 (포트: 8081, 등)
- **Green**: 새 버전 배포 대상 (포트: 8082, 등)
- **전환**: Nginx 리버스 프록시에서 upstream 변경

### 8.2 배포 스크립트

배포 스크립트는 `infra/main-ec2/scripts/` 디렉토리에 위치:

```bash
cd infra/main-ec2/scripts

# 백엔드 배포 스크립트
./deploy-backend.sh

# 프론트엔드 배포 스크립트
./deploy-frontend.sh

# CRDT 서버 배포 스크립트
./deploy-node.sh

# NFT 서버 배포 스크립트
./deploy-nft.sh
```

### 8.3 배포 절차

#### 백엔드 Blue-Green 배포

```bash
# 1. 현재 상태 확인
docker compose -f docker-compose-backend-blue.yml ps
docker compose -f docker-compose-backend-green.yml ps

# 2. Green 컨테이너에 새 버전 배포
docker compose -f docker-compose-backend-green.yml pull
docker compose -f docker-compose-backend-green.yml up -d

# 3. Green 헬스체크
curl http://localhost:8082/api/v3/api-docs

# 4. Nginx upstream 변경 (Blue → Green)
# nginx/conf.d/backend-upstream.conf 편집
# upstream backend {
#   server localhost:8082;  # Blue(8081) → Green(8082)
# }

# 5. Nginx 설정 리로드
docker exec nginx nginx -s reload

# 6. Blue 컨테이너 종료
docker compose -f docker-compose-backend-blue.yml down

# 7. 다음 배포를 위해 Blue/Green 역할 교체
```
